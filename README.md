# PalmTrace — نظام إدارة النخيل والأشجار المستديمة

نظام ويب (PWA) لتسجيل كل العمليات التشغيلية للأشجار والنخيل من الغرس حتى الحصاد والتصدير، مع مركز ذكاء اصطناعي للمهندس والمزارع ولوحة متابعة للمستثمرين.

## التشغيل

المتطلبات: Node.js إصدار 22.5 أو أحدث.

```bash
npm install          # أول مرة فقط
copy .env.example .env   # ثم عدّل القيم (Windows)  —  أو: cp .env.example .env
npm start
```

ثم افتح `http://localhost:3000`. على ويندوز يكفي تشغيل `تشغيل_النظام.bat` (ولإيقاف الخادم أغلق نافذته السوداء). ولحفظ رابط قاعدة Render شغّل `إعداد_قاعدة_Render.bat` والصق الرابط.

قاعدة البيانات في `backend/data/palmtrace.db`. لو لم تكن موجودة تُنشأ قاعدة جديدة فيها حساب `admin` بكلمة مرور مؤقتة تظهر في نافذة الخادم، أو مزرعة تجريبية كاملة إذا كان `SEED_DEMO_DATA=true` في `.env`.

## تسجيل الدخول والأمان

- كل طلبات الـ API تحتاج جلسة دخول (`Authorization: Bearer <token>`) ما عدا: فحص الحالة، صفحة تتبع المستهلك العامة، تسجيل الدخول/استعادة كلمة المرور، ونماذج Excel الفارغة.
- الدخول دون اتصال متاح فقط لآخر مستخدم سجّل الدخول أونلاين على نفس الجهاز.
- المفاتيح السرية (Gemini، كلمة مرور قاعدة Render، SMTP) تُوضع في `.env` ولا تُرسل للمتصفح.
- نسيت كلمة مرور المدير؟ على جهاز الخادم: `npm run reset-admin -- "كلمة_مرور_جديدة"`.
- بدون إعداد بريد إلكتروني، رابط استعادة كلمة المرور يظهر في نافذة الخادم فقط.

## أوامر مفيدة

| الأمر | الوظيفة |
|---|---|
| `npm start` | تشغيل الخادم |
| `npm run dev` | تشغيل مع إعادة التحميل التلقائي عند تعديل الكود |
| `npm run check` | فحص صياغة كل ملفات JavaScript |
| `npm test` | اختبارات الـ API والأمان (تعمل على قاعدة مؤقتة ولا تلمس بياناتك) |
| `npm run db:push` / `db:pull` | مزامنة مع قاعدة PostgreSQL على Render (يتطلب `RENDER_PG_URL`) |

## النشر على Render (عرض تجريبي)

1. في Render: **New → Blueprint** واختر هذا المستودع؛ ملف `render.yaml` بيجهّز كل حاجة.
2. ضع قيمة `DEMO_PASSWORD` (كلمة مرور حسابات العرض: admin, engineer, worker, investor …). اختيارياً: `GEMINI_API_KEY` و `AGROMONITORING_API_KEY`.
3. الباقة المجانية بتنام بعد ~15 دقيقة بدون زوار وبتمسح البيانات عند كل إعادة تشغيل، فالمزرعة التجريبية بتتعمل من جديد. افتح الرابط قبل العرض بدقيقتين. للاحتفاظ بالبيانات: باقة مدفوعة + Disk على `/var/data` و `DATA_DIR=/var/data`.
