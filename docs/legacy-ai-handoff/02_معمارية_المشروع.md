# معمارية نظام إدارة النخيل (النسخة المعتمدة v33)

## الشكل العام
تطبيق صفحة واحدة (SPA) بدون إطار عمل. الحالة كلها في المتصفح.

```
index.html
  ├── css/app.css
  ├── js/store.js     ← Store.get / Store.set / localStorage
  ├── js/app.js       ← كل الشاشات والتوجيه
  ├── sw.js           ← offline cache
  └── manifest.json
```

لا يوجد سيرفر أو قاعدة بيانات بعد. الخطوة التالية للإنتاج: API + مزامنة حقيقية. لا تبدأ بنقل الإطار (React/Vue) إلا بقرار صريح.

## التخزين
- المفتاح: `palmtrace_v5`
- الدالة: `Store.defaultState()` تعيد العينة التجريبية
- أي حقل جديد يُضاف داخل `defaultState` مع قيمة افتراضية حتى لا تنكسر البيانات القديمة

كيانات أساسية:
- settings, varieties, roles, permCatalog, fertilizers, nurseryPrepTypes
- users (role, plots[], palmIds[])
- sectors, plots
- operationCats, operationTypes (requiresMaterial, allowedKinds)
- palms, offshoots, nurseryItems, operations, yields
- charities + الزكاة وطلبات المستثمر

## التوجيه والصلاحيات في app.js
- `current` اسم الشاشة، `extra` / `lastExtra` معرف النخلة أو السجل
- `go(page, id)` يغيّر الشاشة
- النقرات: `data-go="palms"` للتنقل، `data-act="save-palm"` للإجراء
- `session()` المستخدم الحالي
- `hasPerm(id)` و `workerAllowed(plot, palmId)` لنطاق العامل
- المستثمر يرى قطعه فقط وإجمالي الفسائل دون تفاصيل القلع الفردية إلا ما هو مصمم في بوابته

## التكويد (لا تغيّر الصيغة)
دوال مهمة: `buildCode`, `nurseryCode`, `mmYY`, `nextOffshootSeq`

نخلة: `03-12A-F045-0325`
فسيلة مؤقتة: `03-12A-F045-0325-OS01-0825`
مشتل شراء: `{باتش}-{F|N}{تسلسل}-{MMYY}`

## العمليات
- فردية من بطاقة النخلة أو مسح QR
- جماعية: قطاع / قطع متعددة (chips) / نخيل محدد
- `opMaterialRule(typeId)` يخفي المركب والجرعة إذا `requiresMaterial === false`
- الأسمدة من جدول `fertilizers` حسب `allowedKinds`

## المزامنة الحالية
طابور محلي لحالة العملية (`pending` / `synced`) وService Worker للكاش.
ليست مزامنة خادم حقيقية.
